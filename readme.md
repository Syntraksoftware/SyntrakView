# Syntrak View
Syntrak 主控上位机程序

## 技术栈
Python / PyQt6 / Bleak（BLE GATT 客户端）/ PyVista、Qt3D（3D 人偶可视化）

## 项目功能
- BLE 连接：扫描、连接 ESP32-S3 主控、发现服务与特征
- 文件操作：文件列表查询（JSON）、断点续传、BVH 文件下载/上传
- 数据接收：传感器数据解析、实时 3D 人偶骨骼显示
- 欢迎界面、系统信息展示

## 下载协议要点（与固件配套）
- `chr_real` 通道 UUID `c0b0a090-8070-6050-4030-2011ddddbbaa`
- 5 字节分片头（flags + total_le2 + offset_le2），分片最大 239 字节
- 下载超时 3s；**每收到一个有效数据块重置超时定时器**，只有真正长时间无数据才触发超时重传
